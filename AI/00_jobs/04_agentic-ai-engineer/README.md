# 04 · Agentic AI Engineer

- **Type:** Full-time
- **In one line:** Build autonomous AI *agents* — systems that plan, reason, use tools, and complete multi-step tasks with minimal human intervention.
- **Where (examples):** AI-native startups building agents (Sierra, Cognition, Cursor/Anysphere, Adept-style, LangChain), big-tech agent teams, and enterprises + consultancies (Accenture, Deloitte) standing up agentic workflows.

## 🎯 What the work is
- Design agent loops: planning, reasoning, tool/function calling, memory, reflection, retries.
- Orchestrate single- and multi-agent systems; wire tools via MCP; handle long-horizon tasks.
- Make agents reliable in production: guardrails, evals, cost/latency, observability, failure recovery.

## 🧰 Core skills
- Strong backend (Python/TS) + applied LLM; agent frameworks (LangGraph, CrewAI, Agents SDK).
- Tool/protocol design (MCP, A2A); state & memory; rigorous evals for non-deterministic systems.
