# 05 · Applied AI / LLM Product Engineer

- **Type:** Full-time
- **In one line:** Build the product on top of models — agents, RAG, tool use, structured output — and make it reliable in production.
- **Where (examples):** OpenAI, Anthropic, Google, Microsoft; AI-native startups (Perplexity, Cursor/Anysphere, Harvey, Glean, Sierra, Replit, Notion, Ramp, Vercel) and most enterprises building on LLM APIs.

## 🎯 What the work is
- Design LLM features: prompting, RAG, tool/function calling, agents, structured output, guardrails.
- Ship and operate them: latency, cost, evals, and quality regressions in production.
- Pick the right pattern (fine-tune vs RAG vs prompt) and the right model for the job.

## 🧰 Core skills
- Strong backend/full-stack (Python and/or TS); API design; product sense.
- Applied LLM patterns end-to-end; pragmatic evals; cost/latency tradeoffs.
