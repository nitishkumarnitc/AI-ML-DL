## 🎯 What the work is
- Red-team models and agentic systems; find prompt-injection, jailbreak, and tool-abuse paths.
- Build defenses: input/output guardrails, sandboxing, policy, monitoring.
- Increasingly overlaps with **RL environments** that train models to find/patch vulnerabilities.

## 🧰 Core skills
- Security fundamentals + AppSec; adversarial mindset; strong coding.
- Understanding of LLM/agent internals and their failure modes.

## 📈 Market note
Fast-growing as agents get real permissions. A **SecOps/pentest background + LLM knowledge** is a rare combo — and the on-ramp to security-focused RL-environment authoring.
