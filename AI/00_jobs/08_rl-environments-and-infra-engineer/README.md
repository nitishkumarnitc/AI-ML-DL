# 08 · RL Environments & Infrastructure Engineer  ⭐ (this repo's anchor module)

- **Type:** Full-time or contract
- **In one line:** Build the high-fidelity, gradable environments — and the platform that runs dozens of them — that frontier labs train and evaluate agents in.
- **Where (examples):** RL-env vendors / AI data labs (Scale AI, Surge AI, Mercor, Turing, Handshake AI, Invisible, Prime Intellect, Mechanize, Collinear) and frontier labs' internal environment teams.

## 🎯 What the work is
- Recreate real products (GitHub/Stripe/Linear-like) faithfully; expose via OpenAPI + MCP.
- Write rigorous, separated graders; capture trajectories; run models; analyze failures.
- Build the platform: containers, sandboxing, Kubernetes orchestration, CI/CD, observability.

## 🧰 Core skills
- Backend/full-stack + infra (Docker, Kubernetes, CI/CD); API design; test-first.
- Systems thinking; agent intuition; reverse-engineering unfamiliar products fast.

## 📈 Market note
A **brand-new category (2024→)** created by the shift to RL-with-verifiable-rewards and agentic post-training. Demand is surging; many roles are remote/contract, which lowers the barrier to entry.
