## 🎯 What the work is
- Deploy and scale inference: serving frameworks (vLLM/TGI/TensorRT-LLM), autoscaling, GPUs.
- Optimize latency/throughput/cost: batching, KV-cache, quantization, caching.
- Build the ML/LLM platform: pipelines, registries, CI/CD, monitoring, observability.

## 🧰 Core skills
- Cloud + Kubernetes + IaC; strong ops/reliability; performance profiling.
- Model serving internals; cost engineering.

## 📈 Market note
Every company deploying LLMs needs this. **Inference optimization** is especially hot as usage (and GPU bills) scale.
