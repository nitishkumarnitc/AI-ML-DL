# 11 · Agent Evaluation & Data-Pipeline Engineer

- **Type:** Full-time (some contract)
- **In one line:** Build the evals and data pipelines that measure and improve models/agents — the trustworthy signal behind every launch decision.
- **Where (examples):** Scale AI, Surge AI, Mercor, Turing; eval/observability tooling (Braintrust, LangChain/LangSmith, Arize, Weights & Biases); and lab/company internal eval teams.

## 🎯 What the work is
- Design eval suites (offline + online), LLM-as-judge, benchmarks; guard against contamination/saturation.
- Build pipelines: task generation, trajectory capture, automated grading, failure analysis at scale.
- Turn agent runs into clean, gradable data and dashboards teams trust.

## 🧰 Core skills
- Data engineering + strong evals discipline; statistics; clear analysis.
- Grader design; observability; reproducibility.

## 📈 Market note
As agents ship, "does it actually work?" becomes the bottleneck → eval/data roles are growing fast. Heavily overlaps with the RL-environments world (grading = evals).
