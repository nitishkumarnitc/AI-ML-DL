# 12 · RL Environment / Task Author — Contract (output-based)

- **Type:** Remote contractor, part-time
- **In one line:** As a vetted expert, author *one gradable RL environment/task at a time* for frontier-model training — often domain-specialized (e.g., security/CVE-patching).
- **Where (examples):** Expert networks & data labs — Mercor, Micro1, Turing, Handshake AI, Outlier (Scale), Surge AI, Invisible, Prolific.

## 🎯 What the work is
- Build a reproducible environment + task + separate grader that meets a spec, and submit it.
- Common brief: inject/expose a known bug or **CVE** in a repo that a model must find and patch.
- Explain your engineering decisions clearly in writing; iterate on reviewer feedback.

## 🧰 Core skills
- 3+ yrs backend/full-stack in some language (Python/JS-TS/Go/Java/C++/Rust).
- Reason through unfamiliar codebases; test-first; rigorous, un-gameable graders.

## 📈 Market note
**A fast, flexible way to start in this space** — remote, no relocation. Throughput matters since work is output-based; a reusable env skeleton is a big advantage. Domain specialization (security, systems) is valued.
