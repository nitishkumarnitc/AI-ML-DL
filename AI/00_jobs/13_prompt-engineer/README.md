## 🎯 What the work is
- Craft and iterate prompts/system messages; build prompt libraries and patterns.
- Pair with evals to measure prompt changes; design agent instructions and tool descriptions.
- Translate product/UX intent into reliable model behavior.

## 🧰 Core skills
- Deep prompting craft; structured output; strong evals instinct; clear writing.
- Enough coding to wire prompts into an app and measure them.

## 📈 Market note
The pure "prompt engineer" title peaked in 2023 and is **consolidating into applied-AI and eval roles** — the skill is essential, but rarely a standalone job now. Treat it as a strong *component* skill.
