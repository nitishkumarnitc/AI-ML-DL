# Run it

```bash
python run.py
```

No dependencies, runs instantly. FOUR prompt-style variants (zero-shot, few-shot, structured-CoT, and a majority-vote ensemble of the three) scored against a 20-example eval set, with a full confusion matrix per variant (not just aggregate accuracy) and a measured winner written up as a prompt-library entry.

Full write-up, what to look for, and how to extend it: [../project.md](../project.md).
