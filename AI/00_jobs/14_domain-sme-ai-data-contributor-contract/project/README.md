# Run it

```bash
python run.py
python run.py --report-file grading_report.md   # export the full graded report as markdown
```

No dependencies, runs instantly. FIVE hard questions across THREE domains (coding, personal finance, statistics) — proving the rubric-grading pattern really is domain-agnostic — each graded against a good and a subtly-flawed candidate answer, with reviewer-style notes on the consequence of trusting the flawed one.

Full write-up, what to look for, and how to extend it: [../project.md](../project.md).
