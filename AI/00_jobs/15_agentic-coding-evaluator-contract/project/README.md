# Run it

```bash
python run.py
python run.py --report-file comparison_report.md   # export the full comparison as markdown
```

No dependencies, runs instantly. THREE coding tasks, each with two candidate "agent-generated" solutions (one flawed, one correct) that get **actually executed** against a normal test and a deliberate edge case — catching a real runtime failure or wrong result for each flawed candidate and naming which code-hallucination pattern it is.

Full write-up, what to look for, and how to extend it: [../project.md](../project.md).
