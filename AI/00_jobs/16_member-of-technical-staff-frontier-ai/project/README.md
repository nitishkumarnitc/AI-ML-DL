# Run it

```bash
python run.py
python run.py --report-file signal_gate_report.md   # export the full report as markdown
```

No dependencies, runs instantly. Clusters raw ops-signal notes into candidate hypothesis categories by pattern, then runs FIVE research claims through a four-check signal-trustworthiness gate (sample size, annotator agreement, contamination, reproducibility), printing a hard STRONG/BLOCKED verdict plus a specific, falsifiable next step for every claim that isn't ready to externalize.

Full write-up, what to look for, and how to extend it: [../project.md](../project.md).
