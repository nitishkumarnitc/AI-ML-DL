# Acme Returns Policy

## Return window

Acme accepts returns within 30 days of delivery. Items must be unused, in
their original condition, and in the original packaging with all accessories
and documentation included.

## How to start a return

To start a return, sign in and open "My Orders", select the item, and request a
Return Merchandise Authorization (RMA). You can also request an RMA by
contacting support. We provide a prepaid shipping label for eligible returns
within the United States. Write the RMA number on the return package.

## Refunds

Once we receive and inspect the returned item, we issue a refund to your
original payment method within 5-7 business days. Original shipping charges are
non-refundable unless the return is due to an Acme error or a defective item.
You will receive an email confirmation when the refund is processed.

## Exchanges

We do not process direct exchanges. To swap an item for a different size,
color, or model, return the original item for a refund and place a new order.

## Non-returnable items

Some items cannot be returned: gift cards, downloadable software, and clearance
or final-sale items. Personalized or custom-configured products are also
non-returnable unless they arrive damaged or defective.
